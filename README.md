# Market Index Dashboard

一个轻量级的市场指数看板，以单个 HTML 文件展示 A 股、行业、港股、美股和日韩主要指数的最新行情。

## 在线访问

[打开在线指数看板](https://hakunamatata5893.github.io/market-index-dashboard/)

GitHub 仓库：<https://github.com/hakunamatata5893/market-index-dashboard>

## 功能

- 展示指数最新点位、涨跌额和涨跌幅。
- 展示今开、最高、最低、昨收、成交量和成交额。
- 按 A 股、行业指数、港股、美股和日韩分组展示。
- 支持手动刷新行情。
- 红色表示上涨，绿色表示下跌。
- 响应式布局，可在电脑和移动设备中使用。

当前覆盖 19 个指数：

- A 股：上证指数、创业板指、沪深 300、科创 50、中证 A500、中证 1000。
- 行业指数：红利指数、光通信模块、中证半导、机器人、卫星产业、CS 创新药。
- 港股：恒生指数、恒生科技指数。
- 美股：道琼斯、纳斯达克 100、标普 500。
- 日韩：日经 225、首尔综合指数。

## 数据来源

行情数据来自东方财富公开行情接口：

```text
https://push2.eastmoney.com/api/qt/ulist.np/get
```

页面通过 JSONP 获取数据，以便直接在浏览器中运行。数据是否返回、更新时间和字段完整性取决于第三方接口。

## 本地使用

本项目不需要安装依赖或执行构建命令。

1. 下载项目文件。
2. 使用 Chrome、Edge 或其他现代浏览器打开 `指数看板.html`。
3. 保持网络连接，等待行情加载；需要更新时点击“刷新”。

## 自定义指数

如需调整指数范围，可编辑 HTML 中的 `indices` 数组。每项包含以下字段：

```javascript
{ name: "上证指数", secid: "1.000001", code: "000001", market: "A股" }
```

- `name`：页面显示名称。
- `secid`：东方财富接口使用的证券标识。
- `code`：页面显示代码。
- `market`：所属分组，需与 `marketGroups` 中的名称一致。
